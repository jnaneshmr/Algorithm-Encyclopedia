# Algorithm Encyclopedia 🧠💻

A beautifully designed, interactive web application that serves as a comprehensive knowledge base for 30+ essential computer science algorithms. 

## Features ✨

*   **Interactive UI/UX**: Premium aesthetic featuring a deep navy blue and muted gold color palette, inspired by modern, elegant design systems.
*   **Comprehensive Collection**: Covers 30+ algorithms across multiple paradigms (Divide & Conquer, Dynamic Programming, Greedy, Graph, Sorting, etc.).
*   **Multi-Language Implementations**: Explore pseudocode alongside Python, Java, and C++ snippets.
*   **Visualizations**: Conceptual canvas drawings for different algorithm types to help build intuition.
*   **Time Complexities**: Quick reference for Best, Average, and Worst-case Big-O/Theta/Omega bounds.
*   **Practice Integration**: Direct links to LeetCode and GeeksforGeeks to practice the selected algorithm, complete with a quick self-assessment quiz!

## Technology Stack 🛠️

Built entirely with standard web technologies (No frameworks required):
*   **HTML5**
*   **Vanilla CSS3** (Custom properties, Flexbox, Animations)
*   **Vanilla JavaScript** (DOM manipulation, HTML5 Canvas API)
*   **Typography**: Montserrat & Plus Jakarta Sans via Google Fonts.

## How to Run Locally 🚀

Because this project is built with Vanilla HTML/JS/CSS, there is no build step required! 

1. Clone the repository:
   ```bash
   git clone https://github.com/jnaneshmr/Algorithm-Encyclopedia.git
   ```
2. Open the `Algorithm-Encyclopedia` folder.
3. Simply double-click the `index.html` file to open it in your favorite web browser.

## Design Philosophy 🎨

The UI features a "glassmorphism-lite" approach combined with asymmetrical border radii for a sharp, architectural, and premium feel. Custom scrollbars, smooth hover state translations, and sliding active-tab underlines are implemented to ensure a fluid user experience.
